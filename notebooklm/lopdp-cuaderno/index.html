Diseño del sistema

Cada herramienta cumple una función distinta

El Gem no reemplaza a NotebookLM y NotebookLM no reemplaza al Gem. La utilidad aparece cuando la lógica especializada se mantiene separada del corpus documental que evoluciona.

Aplicación práctica

Tres formas de utilizar el sistema conectado

Los siguientes prompts aprovechan la lógica del Gem y el contenido acumulado en NotebookLM. Cada bloque se puede copiar directamente.

01 · AUDITORÍA

Auditar con contexto regulatorio

Uso principal del sistema conectado

Adjunta el contrato o política al Gem y solicita que combine la base legal fija con el contenido del cuaderno.

Prompt sugerido 
Realiza un análisis de cumplimiento según el protocolo estructurado sobre el documento adjunto. Utiliza también el contexto disponible en el cuaderno de NotebookLM conectado para complementar el análisis con resoluciones y criterios regulatorios recientes.
02 · CONSULTA

Consultar criterios recientes

El cuaderno como fuente de actualización

Formula una consulta concreta para revisar qué documentos del cuaderno contienen criterios relacionados con un tema.

Prompt sugerido 
¿Qué criterios recientes existen sobre transferencias internacionales de datos según las fuentes de mi cuaderno de NotebookLM?
03 · COMPARACIÓN

Comparar con casos previos

Utiliza análisis anteriores como referencia

Cuando el cuaderno contenga análisis anteriores, pide al Gem que identifique similitudes, diferencias y patrones.

Prompt sugerido 
Compara el nivel de cumplimiento de este contrato con los contratos de encargado que hemos auditado previamente y que están en el cuaderno.
Mantenimiento

Cómo hacer crecer el corpus

El valor del sistema aumenta cuando el cuaderno se mantiene ordenado, actualizado y conectado con la experiencia obtenida durante casos reales.

Añade nuevas resoluciones

Incorpora resoluciones o guías cuando sean publicadas para mantener disponible el contexto regulatorio más reciente.

Guarda análisis especializados

Añade artículos, análisis jurídicos y casos relevantes como PDF, texto o fuente documental.

Documenta aprendizajes internos

Después de cada caso, registra el contexto y el criterio aplicado. Ese conocimiento tácito puede convertirse en una fuente útil.

Organiza fuentes recurrentes

Mantén documentos regulatorios y materiales internos organizados para evitar duplicados, versiones desactualizadas o referencias ambiguas.

Regla de mantenimiento: revisa periódicamente la calidad, vigencia y procedencia de las fuentes. Un corpus más grande no siempre es un corpus más útil.
Resultado del sistema

Lógica estable, conocimiento en evolución.

El Gem mantiene el método de auditoría. NotebookLM concentra las fuentes que cambian con el tiempo. La separación permite actualizar el contexto sin reconstruir continuamente el asistente.
