Prompts de Sistema vs Prompts de Usuario

La diferencia que separa una simple petición de una instrucción profesional: el sistema define las reglas; el usuario pide una tarea dentro de esas reglas.

Mayor autoridad
El prompt de sistema define rol, límites, formato y comportamiento base.
Tarea puntual
El prompt de usuario expresa qué quiere lograr en ese turno.
Clave profesional
Diseñar el marco antes de pedir el resultado.
Riesgo común
Intentar corregir con prompts de usuario algo que debía vivir en sistema.
⚡
Idea central: no toda instrucción tiene el mismo peso. El prompt de sistema funciona como la constitución de la interacción; el prompt de usuario es la solicitud concreta que debe respetar esa constitución.

Los dos niveles de comunicación

Primero el marco. Luego la petición.

Para trabajar bien con IA, conviene separar las instrucciones que definen cómo debe comportarse el modelo de las instrucciones que piden una tarea específica.

Nivel 1 · Sistema

Prompt de Sistema

Es la instrucción maestra. Define el rol, el tono, los límites, los criterios de calidad y las reglas que deben mantenerse durante la interacción.

Define la identidad operativa de la IA.
Establece restricciones y prioridades.
Persiste más allá de una sola pregunta.
No debería ser reescrito en cada turno.
Nivel 2 · Usuario

Prompt de Usuario

Es la solicitud inmediata del humano. Pide una acción concreta dentro del marco que ya fue definido por el sistema.

Activa una tarea específica.
Cambia según cada necesidad.
Debe respetar las reglas superiores.
Define el resultado esperado en ese momento.
Analogía rápida: el prompt de sistema es el manual de identidad y operación de una marca. El prompt de usuario es el pedido concreto del cliente: “hazme una pieza para Instagram”, “resume este informe” o “convierte esto en una tabla”.
Comparativa práctica

Qué cambia entre sistema y usuario

La diferencia no es solo técnica. Afecta la consistencia, el control del resultado y la forma en que se diseñan herramientas personalizadas.

Dimensión Prompt de Sistema Prompt de Usuario
Función Define el marco de comportamiento. Pide una tarea concreta.
Autoridad Alta. Se prioriza como regla base de la interacción. Menor. Opera dentro de las reglas ya definidas.
Persistencia Se mantiene durante la sesión, herramienta o configuración. Suele durar un turno o una secuencia corta.
Contenido típico Rol, tono, límites, formato, estilo, criterios de calidad. Pregunta, instrucción, archivo a analizar, objetivo inmediato.
Ejemplo “Actúa como analista senior. Responde con estructura ejecutiva, sin relleno y con criterios verificables.” “Analiza este reporte y dame los tres riesgos principales.”
Error común Hacerlo demasiado genérico o contradictorio. Pedir demasiado sin contexto suficiente.
Mejor uso Diseñar comportamiento repetible. Ejecutar una tarea específica.
Jerarquía de instrucciones

La IA no lee todo como si tuviera el mismo peso

Cuando hay varias instrucciones, el modelo intenta responder respetando una jerarquía. Por eso conviene ubicar cada regla en el nivel correcto.

01

Sistema

Define el rol, las reglas permanentes y los límites de operación.

02

Configuración de la herramienta

Puede incluir instrucciones, fuentes, memoria o reglas del espacio de trabajo.

03

Usuario

Formula la tarea del momento: resumir, comparar, redactar, analizar o convertir.

04

Respuesta

El modelo produce una salida intentando respetar el marco superior y la petición concreta.

Constitución

El sistema crea el terreno

Antes de pedir resultados, define cómo debe razonar, escribir, limitarse y estructurar la respuesta.

Pedido

El usuario activa la tarea

El mensaje de usuario debe ser específico: objetivo, contexto, formato esperado y restricciones inmediatas.

Conflicto

La instrucción superior gana

Si el usuario pide algo que contradice el sistema, la IA debería seguir el marco de mayor autoridad.

Aplicación en herramientas reales

Dónde aparece esta lógica en plataformas de IA

Cada plataforma usa nombres distintos, pero la lógica se repite: hay instrucciones estables para configurar el asistente y mensajes de usuario para trabajar en cada turno.

ChatGPT

GPTs personalizados

Equivalente a sistema
Las instrucciones del GPT: rol, comportamiento, estilo, restricciones y formato de salida.
Equivalente a usuario
Cada mensaje que el usuario envía al GPT durante la conversación.
Uso ideal: crear asistentes reutilizables con comportamiento estable.
Gemini

GEMs

Equivalente a sistema
Las instrucciones que configuran el GEM para una función o estilo de trabajo.
Equivalente a usuario
La solicitud concreta que se le hace al GEM en cada interacción.
Uso ideal: guardar patrones de trabajo recurrentes sin reconstruir el briefing cada vez.
Claude

Proyectos

Equivalente a sistema
Las instrucciones del proyecto, junto con el contexto y documentos de referencia.
Equivalente a usuario
Las tareas que se piden dentro del proyecto usando ese contexto estable.
Uso ideal: sostener trabajo largo con contexto, documentos y reglas compartidas.
Ejemplo en acción

La misma tarea mejora cuando separas sistema y usuario

Un buen prompt no es solo “pedir mejor”. Es diseñar la relación entre reglas permanentes y tarea concreta.

Eres un facilitador experto en IA aplicada para estudiantes.

Tu estilo debe ser:
- claro
- práctico
- sin tecnicismos innecesarios
- con ejemplos cotidianos

Cuando expliques conceptos, usa:
1. definición breve
2. analogía
3. tabla comparativa
4. ejemplo de uso
Prompt de usuario tarea 
Explícame la diferencia entre prompt de sistema y prompt de usuario.

Quiero usarlo para crear una actividad de clase de 15 minutos con ejemplos en ChatGPT, Gemini y Claude.

Resultado esperado

La respuesta debería respetar el estilo didáctico definido por el sistema y resolver la necesidad puntual del usuario.

Conceptos que conviene dominar

Cuatro reglas para escribir mejores prompts

Rol

Define quién responde

Un rol claro mejora el criterio de respuesta: analista, tutor, editor, estratega o desarrollador.

Formato

Define cómo debe verse

Tabla, checklist, pasos, resumen ejecutivo, JSON, email o guion. El formato reduce ambigüedad.

Contexto

Da información útil

La IA no adivina bien tus objetivos. Contexto, audiencia y restricciones elevan la calidad.

Criterios

Explica qué es “bueno”

Incluye criterios de evaluación: claridad, brevedad, tono, profundidad, ejemplos o fuentes.

Errores frecuentes

Lo que más rompe un buen flujo de prompting

Meter todo en el prompt de usuario
Si repites rol, tono, formato y restricciones en cada mensaje, estás usando el prompt de usuario para resolver un problema de diseño del sistema.
Crear un sistema demasiado vago
“Sé útil y profesional” no alcanza. Un buen sistema indica cómo responder, qué evitar, qué formato usar y qué criterios cumplir.
Contradecir las reglas superiores
Si el prompt de usuario pide algo incompatible con el marco del sistema, el resultado será inconsistente o el modelo priorizará la regla superior.
No definir el formato de salida
La calidad mejora cuando la IA sabe si debe entregar una tabla, una lista, un análisis, una rúbrica, un email o una guía paso a paso.

Regla final: diseña comportamiento antes de pedir resultados

El prompting profesional no consiste en escribir órdenes más largas. Consiste en separar lo permanente de lo variable: sistema para el marco, usuario para la tarea.

Sistema
Define cómo debe trabajar la IA.
Usuario
Define qué necesita resolver ahora.
Resultado
Mejor consistencia, menos retrabajo y respuestas más útiles.
