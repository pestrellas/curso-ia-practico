¿Qué son los Proyectos?

Un espacio de trabajo persistente dentro de Claude.ai

A diferencia de un chat normal, un Proyecto mantiene disponibles documentos, instrucciones y conversaciones organizadas por tema.

Proyectos
Claude.ai — Anthropic

Los Proyectos son espacios de trabajo especializados y persistentes dentro de Claude.ai. Funcionan como un entorno donde Claude puede consultar documentos, seguir instrucciones específicas y mantener el trabajo organizado por tema. El resultado práctico es que no tienes que reexplicar el contexto cada vez.

Base de conocimiento

Sube documentos una vez. Claude los consulta en los chats del proyecto.

Instrucciones fijas

Define rol, tono, formato y reglas para ese proyecto específico.

Memoria

Claude sintetiza lo aprendido en el proyecto y lo recuerda entre sesiones.

200K tokens

Ventana de contexto base de aproximadamente 500 páginas.

RAG automático

Cuando la base crece, Claude activa búsqueda inteligente sin configuración.

Colaboración

En Team y Enterprise, puedes compartir proyectos con permisos por persona.

Cómo crear y configurar un proyecto

Cinco pasos para pasar de chat suelto a espacio de trabajo

01

Abre Proyectos

En claude.ai, entra a “Projects” desde el panel lateral o ve a claude.ai/projects.

02

Crea el proyecto

Haz clic en “+ New Project”. Añade nombre y descripción para tu organización personal.

03

Escribe instrucciones

Define el rol, tono, formato de salida y reglas de comportamiento de Claude.

04

Sube documentos

Agrega PDFs, DOCX, TXT, CSV, hojas de cálculo, HTML y otros archivos de referencia.

05

Inicia un chat

Abre una conversación dentro del proyecto. Claude ya tendrá el contexto disponible.

!

Dato clave: Claude no tiene acceso al nombre ni a la descripción del proyecto. Esos campos son solo para tu organización personal. Todo lo que Claude necesite saber debe estar en las instrucciones del proyecto o en la base de conocimiento.

Componentes clave

Cuatro piezas que convierten un proyecto en un sistema de trabajo

01

Base de conocimiento

Los documentos que Claude consulta en cada conversación del proyecto.

Todos los planes

La base de conocimiento es el repositorio permanente de información del proyecto. Todo lo que subas aquí queda disponible para Claude sin tener que adjuntar archivos manualmente en cada conversación.

Formatos PDF, DOCX, TXT, CSV, HTML, ODT, RTF, EPUB, JSON, XLSX. Imágenes: JPEG, PNG, GIF y WebP.
Límites 30 MB por archivo. Hasta 20 archivos por chat individual. La base del proyecto está sujeta a la ventana de contexto.
RAG auto Cuando el volumen supera la ventana de contexto, Claude activa búsqueda inteligente automática. El contenido en caché no consume límites de uso.
1

Usa nombres descriptivos

Los archivos deben indicar claramente qué contienen. politica-precios-2025.pdf funciona mejor que doc_final_v3.pdf.

2

Agrupa fuentes relacionadas

Un proyecto funciona mejor cuando sus documentos pertenecen al mismo cliente, producto, proceso o área de trabajo.

3

Referencia documentos por nombre

En tus preguntas puedes indicar exactamente qué documento debe usar Claude.

Basándote en el documento “reglamento-interno-2025.pdf”, ¿cuál es el procedimiento para...?
4

Prueba antes de producción

Carga de 3 a 5 documentos representativos y compara las respuestas con el resultado esperado.

02

Instrucciones del proyecto

El system prompt permanente que define cómo se comporta Claude.

Todos los planes

Las instrucciones del proyecto funcionan como un system prompt permanente con alcance limitado a ese proyecto. Se activan automáticamente en cada conversación y no afectan otros proyectos ni chats fuera de ese espacio.

Puedes definir Rol de Claude, idioma, tono, formato de salida y restricciones específicas.
Jerarquía Tienen prioridad sobre preferencias globales de perfil y pueden combinarse con estilos por conversación.
Límite práctico Conviene mantenerlas concisas y dejar instrucciones muy específicas para el chat individual.
1

Define el rol

Explica qué papel cumple Claude en ese proyecto.

Eres un asistente especializado en análisis de contratos B2B. Tu objetivo es identificar cláusulas de riesgo, inconsistencias y oportunidades de mejora.
2

Establece tono y formato

Indica idioma, formalidad y estructura esperada.

Responde siempre en español formal. Usa tablas comparativas cuando analices más de dos opciones. Evita tecnicismos sin definición.
3

Agrega restricciones

Define qué debe evitar o pedir Claude antes de responder.

Cuando falte información, pide aclaración antes de proceder. No asumas datos numéricos que no estén en los documentos cargados.
4

Usa una guía de estándares

Puedes pedir a Claude que genere una guía a partir de los documentos cargados y luego usarla como referencia permanente.

03

Memoria del proyecto

Cómo Claude retiene y comparte contexto entre conversaciones.

Pro, Max, Team, Enterprise

La memoria de proyecto es un resumen dedicado que Claude construye y actualiza a partir de las conversaciones del proyecto. Es independiente de la memoria general de la cuenta.

Actualización Claude actualiza el resumen cada 24 horas. Si le dices “recuerda esto”, la memoria se actualiza de inmediato.
Búsqueda Puede buscar en chats previos del proyecto para responder preguntas como “¿qué decidimos sobre X la semana pasada?”.
Control Puedes ver y editar memorias desde configuración, o pedir a Claude que olvide o corrija información específica.
Elemento ¿Se comparte entre chats del mismo proyecto?
Base de conocimiento Sí — disponible en todos los chats.
Instrucciones del proyecto Sí — aplican automáticamente.
Resumen de memoria Sí — se actualiza cada 24 horas.
Contenido de un chat individual No — cada chat tiene contexto aislado.
Archivos adjuntos en un chat No — solo visibles en esa conversación.

Implicación práctica: cuando una conclusión debe vivir en el proyecto, dile “recuerda esto”, añádela a la base de conocimiento o espera el ciclo de memoria.

04

Colaboración en equipo

Proyectos compartidos con permisos y control de acceso.

Team y Enterprise

En Team y Enterprise, los Proyectos pasan de ser espacios individuales a una infraestructura de trabajo colaborativo. El equipo puede usar la misma base de conocimiento, instrucciones y configuración.

Funciones Directorio de proyectos compartidos, notificaciones, feed de actividad y permisos por persona o grupo.
Enterprise Agrega ventanas de contexto de 500K tokens, logs de auditoría, SSO, retención personalizada y conectores.
Seguridad El contenido de Proyectos no se usa para entrenar modelos sin consentimiento explícito del usuario u organización.
Nivel de permiso Qué puede hacer
Can use Iniciar chats y consultar la base. No puede modificar instrucciones ni documentos.
Can edit Puede editar instrucciones, agregar documentos o eliminar archivos de la base de conocimiento.
Owner / Admin Control total: permisos, archivado, eliminación y configuración avanzada.

Comparaciones

Cuándo conviene usar Proyectos y cómo se comparan con otras opciones

Proyectos vs. chat normal

La diferencia principal es la persistencia: documentos, instrucciones y memoria viven en el proyecto.

Característica Chat normal Proyecto
Contexto al iniciar Cero — empieza en blanco. Persistente — instrucciones + documentos.
Documentos Se adjuntan por chat. Base permanente.
Instrucciones Solo preferencias globales. System prompt por proyecto.
Memoria entre sesiones Memoria general de la cuenta. Resumen dedicado.
RAG automático No disponible. Sí en planes de pago.

GPTs y Gems vs. Proyectos de Claude

GPTs y Gems nacen con lógica de producto distribuible. Los Proyectos de Claude están pensados como espacios personales o de equipo orientados al flujo de trabajo.

Característica GPTs / Gems Proyectos Claude
System prompt personalizado Sí Sí
Base de conocimiento Sí Sí
Historial agrupado No — cada chat empieza nuevo. Sí
Memoria entre sesiones No Sí en planes de pago.
Publicable como app Sí No disponible
Orientación principal Producto — distribución a usuarios. Flujo de trabajo — uso personal o equipo.
↗

Lo que Claude no tiene: no existe un equivalente directo al GPT Store ni a una galería pública de Gems. Para crear un asistente distribuible en el ecosistema Anthropic, la vía es usar la API de Claude con interfaz propia.

Proyectos de ChatGPT vs. Proyectos de Claude

La filosofía es muy parecida: ambos agrupan conversaciones por tema, mantienen instrucciones persistentes y comparten una base de conocimiento.

Característica Proyectos ChatGPT Proyectos Claude
Agrupa conversaciones Sí Sí
Instrucciones personalizadas Sí Sí
Base compartida Sí Sí
Memoria entre conversaciones Sí Sí en Pro, Max, Team y Enterprise.
Ventana de contexto base ~128K tokens 200K tokens
Ventana con RAG Variable Hasta 2M tokens
Tamaño máximo por archivo Variable por plan 30 MB por archivo
✓

Conclusión práctica: si ya usas Proyectos en ChatGPT, la curva de aprendizaje en Claude es baja. La ventaja de Claude está en su ventana de contexto más amplia y el caché de contenido.

Buenas prácticas

Cómo evitar proyectos desordenados

Un proyecto por área clara

Crea espacios separados por cliente, producto, área funcional o flujo de trabajo bien delimitado.

Evita el “cajón de sastre”

No mezcles temas sin relación. El valor está en que Claude tenga el contexto correcto para la tarea correcta.

Documentos repetidos van a la base

Todo material que usarás varias veces debe vivir en la base de conocimiento, no adjuntarse chat por chat.

El valor está en no repetir contexto

Los Proyectos convierten Claude en un entorno de trabajo persistente. Úsalos cuando necesites continuidad, documentos compartidos, reglas claras y conversaciones organizadas por tema.
