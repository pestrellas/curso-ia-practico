Framework de lectura

T.C.R.E.I. aplicado en clase

El objetivo no es memorizar prompts, sino entender qué pieza hace que funcionen: tarea, contexto, referencia, evaluación o iteración.

T

Tarea

Define la acción principal.

C

Contexto

Ubica el caso y la audiencia.

R

Referencia

Marca rol, estilo o modelo.

E

Evaluación

Controla calidad y formato.

I

Iteración

Mejora el primer resultado.

Tip de clase: cuando el resultado salga flojo, no cambies todo el prompt. Primero identifica qué pieza falló: falta de contexto, criterios débiles, rol confuso o ausencia de iteración.

Flujo recomendado para practicar en vivo

Usa cada prompt como una demostración breve: ejecuta, observa, cambia una variable y compara. La diferencia entre versiones es donde aparece el aprendizaje.
