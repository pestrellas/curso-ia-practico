Framework de práctica

Estructura T.C.R.E.I.

Cada ejercicio separa el prompt en cinco piezas para que puedas entenderlo, mejorarlo y adaptarlo a tu caso.

T

Tarea

Qué debe hacer la IA.

C

Contexto

Situación, empresa o audiencia.

R

Referencia

Tono, estilo o formato.

E

Evaluación

Criterios mínimos de calidad.

I

Iteración

Variación para profundizar.

Tip: no copies el prompt sin pensar. Primero revisa la estructura, luego ajusta el contexto con datos reales y finalmente prueba la iteración.

Cómo practicar sin quedarte en teoría

La mejora real aparece cuando comparas versiones. Usa cada ejercicio como un ciclo corto de entrenamiento, no como una plantilla fija.

01

Ejecuta

Prueba el prompt base tal como está.

02

Evalúa

Revisa si cumple la tarea y criterios.

03

Ajusta

Agrega contexto real y restricciones.

04

Itera

Pide una segunda versión enfocada.

05

Compara

Quédate con la versión más usable.
